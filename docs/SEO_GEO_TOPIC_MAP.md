## Cannibalization 规则

- `supplement manufacturer / factory / supplier / OEM supplier` 视为同一商业意图，不建立近义克隆页。
- Insights 使用问题型、比较型和尽调型意图；剂型页保留 `{format} manufacturing` 商业主词。
- “prepare for OEM / ODM” 负责首轮 brief；未来 RFQ 文章负责正式询价字段，两者不得复制主体内容。
- “choose format” 是八剂型总决策页；单剂型文章只解释该剂型的项目变量。
- “prepare for OEM / ODM” 负责进入项目前的 brief；“sampling” 负责进入开发后的验证、记录与 scale-up 边界。
- “choose format” 覆盖八剂型上层框架；“gummies vs hard capsules” 只解决两个明确候选之间的取舍。
- “evaluate a manufacturer” 负责供应商整体评估；“documents buyers should ask for” 深入文件类别、主体、范围、有效期与适用性，两类 Quality 问题由后者统一回答。
- “prepare for OEM / ODM” 负责 broad project brief；“information to include in an RFQ” 负责正式询价的结构化字段、假设状态与商业问题。
- “packaging affects MOQ and lead time” 解释约束因果，不承接 Products 或 OEM 页的商业主词，也不发布 VITHELO 条件。
