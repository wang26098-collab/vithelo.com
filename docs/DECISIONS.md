# 关键决策

- 公开品牌只使用 `VITHELO`；源资料中的公司名称和标识不进入公开页面。
- 首页主图锁定，不替换、不视差、不重新生成。
- 首页按采购决策链组织；产品剂型保持一个完整区块，产品方向保持纵向叙事。
- 未核实的公司身份、认证、产能和客户覆盖事实不以营销语气公开。
- 询盘默认采用无存储预填 Email / WhatsApp，除非表单服务、隐私和路由责任全部确认。
- 剂型页采用单一动态 App Router 框架与格式记录驱动，允许每种格式保留真实差异，避免 8 份克隆页面。
- BreadcrumbList 仅在实际 `/products/{slug}` 页面层级上输出，canonical 继续由 metadata 配置生成。
