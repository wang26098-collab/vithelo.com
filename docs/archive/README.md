# VITHELO archive

This directory preserves superseded project history and frozen visual references. None of these files is a deployable application source.

- `legacy-homepage-preview/`: frozen standalone HTML previews and their original checks.
- `legacy-design-system/`: superseded generated design-system material.
- `project-history/`: completed audits, handoffs, change logs, and savepoints.
- `plans/`: completed or superseded implementation plans.
- `source-briefs/`: original project briefs retained for provenance.

The deployable Next.js application remains at the repository root. Historical HTML previews must remain byte-for-byte unchanged.
