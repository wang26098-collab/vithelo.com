# VITHELO B2B 首页实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留现有单文件首页与视觉基底的前提下，将其升级为已确认的 11 板块美国市场 B2B 采购决策首页。

**Architecture:** 继续采用单个 HTML 文件、Tailwind CSS v3 CDN 和 Vanilla JavaScript；页面事实写入 HTML 的集中数据块并由渲染函数填充需要交互的区域，静态关键内容保留在 HTML 中作为无 JavaScript 回退。图片先使用明确标注尺寸与类型的本地占位路径，正式素材到位后只替换资源文件，不改变板块结构。

**Tech Stack:** HTML5、Tailwind CSS v3 CDN、原生 CSS、Vanilla JavaScript、Node.js 内置 `node:test` 静态契约测试、浏览器人工响应式与无障碍检查。

## 0. 范围边界

本计划只实施首页，不创建 Gummies、Solutions、OEM/ODM、Manufacturing、Quality、About 或 Contact 独立页面。指向这些页面的链接在第一阶段使用可识别的暂存路径，并在链接附近保留 `NOT_CONFIGURED` 数据状态；不得伪造已经存在的页面、表单服务、Email 或 WhatsApp。
