# VITHELO 项目当前状态

最后更新：2026-09-01

本文档是当前项目进度、已确认决策和下一步工作的入口。历史设计规范与本文冲突时，以本文和用户最新明确指令为准；历史文件继续保留作为过程记录，不代表当前实现。

## 当前产品形态

- 对外品牌统一为 `VITHELO`。
- 当前网站是面向营养健康产品 OEM / ODM、私人标签与项目询盘的英文 B2B 独立站。
- 当前公开路由：`/`、`/products`、`/oem-odm`、`/insights`、`/insights/[slug]`、`/contact`。
- 首页承担品牌建立、制造能力说明、产品剂型展示、项目方向解释和询盘引导，不承担支付或在线提交。

## 已确认的首页规则

- 首页主图已经完成并锁定：不得替换、缩放、位移、视差或重新生成。
- 首页当前收为八屏：Hero、制造证明、制造能力仪表盘、软糖能力、产品方向、产品剂型、OEM / ODM 项目路径、询盘收口。
- 新增第三屏为制造能力仪表盘；使用用户提供资料中的剂型与产能数据，保留生产核验和公开使用批准边界，不展示 `audited` 或虚构年度增长曲线。
- 第四屏保持原生纵向滚动叙事；不得显示页码、左右箭头或改成横向轮播。
- 八种产品剂型必须在同一屏完整出现；口溶膜不得因网格余数单独占据一行。
- 首页不恢复无效或禁用的询盘表单。Email 与 WhatsApp 是主要询盘路径。
- 动效只用于合适的内容屏。主图静止；软糖能力、产品剂型和项目路径可使用进入视口后的分批揭示；Reduced Motion 必须显示完整静态内容。
- 不再整页推翻重做。后续按单屏锁定目标、确认方案、实施和验收。

## 第二屏当前设计决策

- 当前只重做第二屏，第三屏及之后暂时不动。
- 已选择视觉方向 `V-A Editorial Proof Ledger`：冷调克制、编辑式大字、非对称图文和数字证据账本。
- 第二屏任务是从产品主图过渡到制造信任，不使用概念型能力标签、通用图标卡或巨大的 `NOT_CONFIGURED`。
- 拟使用的源资料数字：始于 2008、软胶囊 50B 粒/年、软糖 5,000+ 吨/年、片剂 36B 片/年；辅助说明为服务 5,000+ 客户、覆盖 50+ 国家和地区。
- 上述数字来自用户提供的 `独立站内容/森酷企业介绍(2).pdf`，在完成生产核验前必须保留“用户提供资料”边界。
- 第二屏只使用不含原公司名称和原品牌标识的实验室或生产空间画面。图片保持静止。
- 详细规范见 [首页第二屏设计规范](superpowers/specs/2026-09-01-vithelo-home-screen-two-design.md)。

## 公开身份与内容边界

- 页面、元数据、图片文字和替代文本中只允许公开 `VITHELO`。
- 不得公开资料来源中的公司中文名、英文名或原品牌标识。
- 不得把资料中的 GMP、HACCP、Halal、ISO、FDA、COA 或第三方检测图标直接当作 VITHELO 已核实认证。
- 不得自行增加功效、剂量、法规、认证、产能、MOQ、交期、价格或市场合规结论。
- 用户提供但尚未完成生产核验的数据必须明确标记来源边界；缺失内容继续使用 `NOT_CONFIGURED`。
