# VITHELO About 页面设计规范

日期：2026-09-20  
状态：用户已确认页面方向、叙事结构、视觉语言与实现边界

## 1. 目标

本轮只重做公开路由 `/about`。页面需要把 VITHELO 的品牌气质与营养品 OEM / ODM 制造角色放在同一条叙事中：既不能只是品牌宣言，也不能退化为常见的蓝色工厂企业站。

参考分工固定如下：

- Nordicus 只提供审美机制：沉浸影像、纯白内容体、深浅章节、留白比例、横向台账和建筑式页面节奏。
- Yile Health 只提供内容类型：制造角色、产品剂型、开发、生产、质量与文件、跨职能支持和买家问题。
- 不复制两者的品牌、文案、图片、数字、认证、联系方式、表单或企业事实。

## 2. 范围

### Must

- 新建独立 About 页面模式，不继续用现有通用信息页拼装。
- 建立 About 专属内容契约与本地适配器入口。
- 完成桌面、平板、手机和 Reduced Motion 适配。
- 保持 VITHELO 身份、证据边界和直接询盘路径。
- 增加定向单元测试与 E2E 验收。

### Should

- 复用已在项目内登记为演示用途的制造与产品场景素材。
- 通过页面比例与场域切换建立 Nordicus 式高级感，而非依赖装饰效果。
- 让海外买家能快速理解 VITHELO 的角色、工作方式和能力边界。

### Could

- 在不影响信息可见性的前提下加入轻量顺序揭示。

### Won't

- 不改首页、导航、OEM / ODM、Manufacturing、Quality 或 Contact 的现有设计。
- 不新增服务端表单、CMS、CRM、分析或第三方集成。
- 不生成或虚构公司规模、厂房面积、产量、客户数、认证、市场覆盖、MOQ、交期或团队履历。
- 不复制 Yile 的蓝色企业站风格，也不复制 Nordicus 的建筑项目、字体体系或品牌表达。

## 3. 页面叙事

页面由七段组成，保持连续纵向阅读，不使用横向轮播或滚动劫持。

### 3.1 品牌 × 制造首屏

- 使用低饱和制造场景作为全幅背景。
- 左下安全区显示 `ABOUT VITHELO`、主标题、简短说明和两个行动入口。
- 推荐主标题：`Purpose in every decision. Precision in every handoff.`
- 说明必须在首屏明确 VITHELO 是营养品 OEM / ODM 制造合作伙伴。
- 行动入口为 `Explore Our Capabilities` 与 `Start a Project`。

### 3.2 我们的角色

- 纯白内容体从首屏底部进入，顶部保留克制圆角，左右与视口贴齐。
- 左侧说明 VITHELO 如何连接产品构想、开发决策与制造路线。
- 右侧使用项目现有演示素材建立产品与制造语境。
- 内容体内部保留响应式安全边距；外部不得出现两侧灰色沟槽。

### 3.3 工作原则台账

使用四行横向台账，桌面每行包含编号、原则与真实行为说明；移动端自然重排。

1. `Context`：从产品目标、剂型和包装语境开始。
2. `Precision`：在确认前明确范围、输入和待验证事项。
3. `Continuity`：让开发、生产与文件讨论保持连接。
4. `Collaboration`：围绕同一份项目简报协调跨职能判断。

这些词不能作为空泛价值观独立存在，每项必须对应可理解的项目行为。

### 3.4 制造能力长镜头

- 进入近黑石墨场域，以一个连续章节串联产品定义、配方与打样、生产体系、质量与文件。
- 使用长幅影像、细分隔线与大尺度文字，不使用四张等宽悬浮卡片。
- 所有能力表达必须条件化，避免把演示内容包装成已核实证明。

### 3.5 八种剂型能力

- 在一个完整章节中呈现现有八种口服剂型，Oral Films 不得被孤立。
- 使用宽幅影像和紧凑索引，不复制首页剂型区的卡片布局。
- 提供到 `/products` 的明确入口。

### 3.6 团队与合作方式

- 说明商业沟通、产品开发、生产评审与质量文件需要跨职能协作。
- 不声明具体团队规模、从业年限、职位人数或未经核实的人员资质。
- 视觉重点是一个项目如何保持连续，而不是展示虚构人物履历。

### 3.7 证据边界与询盘收口

- 明确公司法定主体、公开地址、认证、产能和市场覆盖仍需生产核实或配置。
- 不使用认证标识或客户 Logo。
- 以 `Start a Project` 和直接询盘说明完成页面。

## 4. 视觉系统

### 4.1 色彩

色彩关系以用户确认的 Nordicus 气质为准：

- 主阅读面使用纯白 `#FFFFFF`，不是偏暖矿物白。
- 影像采用雾蓝灰、低饱和钛金属和冷调阴影。
- 深色章节使用近黑石墨。
- 暖琥珀只允许存在于摄影光线中，不作为按钮、链接、状态或大面积主题色。
- 不引入企业蓝、营养绿或新的页面级色彩家族。
- 新的可复用纯白语义值应进入 `src/styles/tokens.css`，页面组件不得散落硬编码色值。

### 4.2 几何

- 首屏为全幅场景。
- 纯白内容体左右贴齐视口，顶部圆角，底部保持连续页面表面。
- 圆角只用于内容体进入首屏的建筑式转折和电影画幅，不扩散成通用圆角卡片。
- 主要章节通过留白、分隔线和背景场域区分，不使用悬浮阴影卡片网格。

### 4.3 字体

- 延续 VITHELO 现有精密无衬线体系。
- 不复制 Nordicus 的衬线标题或建筑品牌排版。
- 高级感来自字号比例、行宽、留白和影像关系。

### 4.4 动效

- 只允许图片显现、台账顺序揭示和章节过渡。
- 动效语义为 `ORIENT`、`RELATE` 或 `EXPLAIN`。
- 不做视差、鼠标跟随、滚动锁定、滚动劫持或内容解码。
- Reduced Motion 下直接显示最终状态，内容顺序和可见性不变。

## 5. 内容与数据边界

- 新增 About 页面 Zod Schema、推断类型、`DEMO_ONLY` fixture 和本地内容适配器方法。
- 页面模式只消费已验证内容，不在路由或 JSX 中定义制造事实。
- 演示影像保留 `DEMO_ONLY` 状态与诚实替代文本。
- `sanitized-factory-production-line.jpg` 若用于本页，继续标记为演示制造场景，不可作为 VITHELO 厂房所有权证明。
- Yile 的厂房面积、产量、洁净等级、客户数、市场覆盖、认证和人员资历不得进入公开文案。
- 缺失的法定主体、地址、认证、产能和市场信息保持 `NOT_CONFIGURED` 或明确的待核实表达。

## 6. 组件边界

- `src/app/about/page.tsx`：只负责元数据与读取内容。
- About 专属页面模式：负责七段页面组合和语义结构。
- About 专属 CSS Module：负责页面几何、响应式和动效，不修改已接受首页的几何声明。
- `src/content/schema.ts`：新增 About 契约。
- `src/content/demo/vithelo-b2b-site.ts` 或聚焦的 About fixture：提供契约化演示内容。
- `src/lib/content.ts`：提供适配器读取方法。
- 现有 `VitheloInformationPage` 继续服务其他信息页，本轮不重构。

## 7. 响应式与可访问性

- 桌面端采用宽幅非对称网格与横向台账。
- 平板端压缩为两列或错位单列，不允许横向溢出。
- 手机端按语义顺序单列呈现；CTA 触控目标至少 44px。
- 标题层级保持一个 `h1`，后续章节使用顺序合理的 `h2`、`h3`。
- 图片替代文本只描述场景，不暗示所有权、认证或生产事实。
- 键盘焦点清晰可见；无 JavaScript 与 Reduced Motion 下仍能读取全部信息和进入询盘。

## 8. 验收

### 定向单元测试

- About fixture 通过 Zod 解析。
- 页面只出现一个 `h1`，七段主要叙事均渲染。
- 八种剂型完整出现，Oral Films 未被单独脱离。
- `DEMO_ONLY` 与待核实边界保持可验证。
- 禁止出现参考站名称、认证声明和未经批准的数字证明。

### 定向 E2E

- 覆盖六个项目验收视口。
- 无水平溢出、裁切、遮挡或两侧灰色沟槽。
- 首屏同时表达品牌与制造角色。
- 手机顺序、导航、CTA、键盘焦点与 44px 目标正确。
- Reduced Motion 下所有事实直接可见。

### 视觉验收

- 页面呈现 Nordicus 式冷雾影像、纯白内容体和深石墨章节。
- 不出现常见蓝色工厂企业站、绿色营养模板、圆角卡片矩阵或大面积暖棕。
- 不复刻参考站品牌；页面必须一眼属于 VITHELO。
- P0 = 0，P1 = 0，并由用户完成最终视觉接受。

## 9. 成功标准

海外买家在第一屏同时理解 VITHELO 的品牌气质与制造角色；继续滚动后能快速掌握其工作方式、剂型范围、开发与质量讨论边界，并在没有被虚构证明误导的前提下进入直接询盘。
