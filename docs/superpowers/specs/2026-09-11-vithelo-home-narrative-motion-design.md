# VITHELO 首页叙事与动效统一设计

## 目标

在不改变导航、八屏顺序、各屏高度、屏内上下间距和左右间距的前提下，让首页形成连续的 B2B 决策叙事，并把动效收敛为一套克制、可预测的语言。

## 不可变边界

- 导航组件、导航状态和导航断点不修改。
- 八屏顺序保持：Hero → 制造证明 → 主打产品 → 定制能力 → 产品方向 → 产品剂型 → OEM / ODM 路径 → 询盘。
- Hero 背景图保持当前文件、尺寸、定位和静止状态。
- 每屏现有 `height`、`min-height`、`padding-block`、`padding-inline` 和四向 `padding` 值不修改。
- 第五屏继续使用原生纵向滚动和现有三段 `100svh` 轨道，不增加横向切换、页码或按钮。
- 第六屏继续在同一内容区展示八种剂型，双列/单列结构和偶数卡片静态错位不修改。
- 第八屏的 `--inquiry-stage-height` 和 `--inquiry-scroll-distance` 不修改；锚点、键盘焦点、无 JavaScript 和 Reduced Motion 直达能力保留。

## 叙事职责

1. Hero：说明 VITHELO 是什么制造伙伴。
2. 制造证明：回答“为什么可以信任这套制造系统”。
3. 主打产品：展示完成后的产品世界与市场呈现。
4. 定制能力：解释 Formula、Dosage Form、Flavor & Taste、Packaging 如何关联。
5. 产品方向：从消费场景和使用习惯出发，说明如何形成产品 brief；不再重复第三屏的瓶装产品卡。
6. 产品剂型：回答 brief 可以落在哪八种产品表达上。
7. OEM / ODM 路径：说明从 brief 到交付的六步推进方式。
8. 询盘：把决策直接交给 Email、WhatsApp 和本地询盘编辑器。

## 动效语言

- Hero 完全静止，不再执行文案入场动画。
- 制造证明使用一次性淡入/上移揭示，数字保持真实终值，不再从零滚动。
- 定制星图保留为页面唯一重点关系动效；只有该关系场景可以使用 900ms token。
- 第五屏每一故事必须先完整退出，再让下一故事进入，禁止两层文字或图片同时半透明叠加。
- 第六屏取消标签乱码解码、指针视差、滚动惯性和左右对向入场；标题与卡片只做同方向轻量上移淡入。
- 第八屏保留 VITHELO 字标遮罩，但在现有滚动距离内更早结束遮罩并更早让联系内容达到完全不透明。
- 时长只使用 150ms、240ms、500ms 和定制关系场景的 900ms；统一使用 `cubic-bezier(0.2, 0, 0, 1)`。

## 内容与素材

- 第三屏现有三张产品图保持不变。
- 第五屏改用现有、已进入项目的场景素材：日常饮用场景、抽象流动材质、女性日常场景。素材继续保留现有证据状态，不新增功效或认证表达。
- 第五屏标题改为 `From routine to product brief.`，三段正文从产品描述改为 brief 构建逻辑。

## 验收

- 六个验收视口的八屏顺序、导航边界、屏高和 padding 与提交 `91cd157` 一致。
- 第五屏标题可见，任意滚动位置最多只有一条故事达到可见状态，不出现幽灵叠字。
- 第六屏 DOM 中始终保留真实剂型名称，运行时不产生替代乱码；无 pointermove 和 scroll 惯性监听。
- 第八屏在滚动进度 75% 时联系内容完全可交互；直达与 Reduced Motion 仍立即显示完整内容。
- P0/P1 为零，无裁切、重叠、横向溢出或新增未经核实的公开事实。
