# VITHELO 女性软糖首页首屏设计规范

日期：2026-08-23
状态：用户已确认设计方向，等待书面规范复核
范围：首页第一屏，不包含后续页面与 Phase B 代码实施

## 1. 设计目标

首页第一屏以一款女性健康旗舰软糖建立 VITHELO 的第一品牌印象。首屏首先服务 B 端合作询盘，同时让 C 端访客立即识别这是一个以营养品为核心的品牌。

第一屏不承担产品功效解释、配方证明、价格展示或多品类导航。它只完成三件事：

1. 让访客在数秒内识别女性营养软糖。
2. 建立冷静科学、真实人性和高端材质并存的品牌气质。
3. 将 B 端访客引导至合作咨询。

## 2. 设计判断

页面类型：高端营养品牌首页首屏。

核心受众：营养品牌采购方、渠道方、OEM/ODM 与 Private Label 合作方。C 端消费者为辅助受众。

视觉语言：Scientific Material Humanism，以冷 Ivory、Graphite、Titanium 和克制 Optical 光线为基础。女性感只通过真实自然肤感、透明红色小熊软糖、柔光和人物姿态表达。

设计参数：

- `DESIGN_VARIANCE: 7`
- `MOTION_INTENSITY: 6`
- `VISUAL_DENSITY: 3`

设计模式：在现有信息架构、品牌公式和工程基线上进行定向重构。不得改变路由、主导航职责、数据边界或 Phase A 验收基线。

## 3. 首屏构图

### 3.1 桌面端

首屏使用 `min-height: 100dvh`，顶部包含不超过 80px 的透明导航。主体采用左文右图的非对称构图，但右侧不是独立图片卡片，而是一张覆盖整个首屏的完整摄影背景。

- 左侧约 42% 为冷 Ivory 文字安全区。
- 右侧及中部约 58% 为人物与产品共景。
- 真实女性侧脸、肩颈和少量手部位于右后方。
- 人物不直视镜头，表情平静，皮肤保留真实纹理，不做高饱和粉色妆容。
- 女性软糖瓶位于右侧前景，是画面锐度、对比度和视觉重量最高的对象。
- 包装必须完整可辨，不被人物、文字、导航或软糖遮挡。
- 三至五颗透明红色小熊软糖分布在瓶身前后，以近景虚化、中景清晰和弱反射建立景深。
- 不增加漂浮胶囊、植物叶片、实验室器皿或微生物图形。

画面不是人物代言广告。人物负责 Human，包装负责 Precision，软糖材质负责 Material。

### 3.2 移动端

移动端保持单一完整画面，不将人物和产品拆成两张图。

- 人物退至上半部和右后方，允许裁切头顶或肩部，但不得只剩无意义皮肤色块。
- 产品位于下半部中央偏右，包装主标识保持可读。
- 标题位于左上至中部的稳定留白区。
- 主按钮必须在首屏内可见，且触控高度不小于 44px。
- 不依赖 hover、横向拖拽或滚动后才显示首屏核心信息。

## 4. 颜色与材质

页面保持单一冷色主题：

- 主背景：冷 Ivory。
- 主文字与按钮：Graphite。
- 包装和反射：Titanium、smoke black 或经批准的冷银材质。
- 唯一高彩度视觉：透明红色小熊软糖。
- Optical 光线只用于产品边缘、玻璃感反射和焦点提示。

禁止大面积粉色、紫色或暖米色背景。禁止绿色营养频道化表达。禁止蓝色科技频道化表达。透明红不得扩散成整屏红色渐变。

形状系统遵循现有品牌规范：包装与版式以 0-8px 小圆角为主，按钮沿用已经批准的 Core Component 规则，不新增页面局部圆角体系。

## 5. 文案与操作

首屏可见文案锁定为：

### Headline

`WOMEN’S NUTRITION, SHAPED WITH PRECISION.`

### Supporting copy

`A flagship gummy platform for differentiated formulas, brand programs and professional partnerships.`

### Primary action

`START A PROJECT`

按钮跳转至 `/contact`，并沿用现有 Contact 意图初始化机制。首屏只有一个主按钮，不增加 `SHOP NOW`、`LEARN MORE`、评分、价格、折扣、功效标签或第二个同义询盘按钮。

如产品事实仍未批准，首屏继续使用可见 `DEMO_ONLY` 边界。不得用视觉处理让概念包装看起来像已上市或已获得认证的真实产品。

## 6. 导航关系

主导航保持现有信息架构和单行桌面布局。导航位于画面顶部，通过局部对比控制确保文字始终可读。

- 不改变路由和主导航标签。
- 不使用促销条、倒计时或滚动提示。
- 不让 Logo、导航或询盘按钮遮挡产品包装。
- 移动菜单继续沿用现有键盘操作、焦点恢复和遮罩行为。

## 7. 动效

动效目的仅限于 `ORIENT`、`FOCUS` 和 `RESPONSE`。

### 初始进入

- 人物背景在 500-600ms 内以轻微透明度变化进入。
- 产品使用更短、更清晰的 400-500ms 进入，确保产品先于装饰软糖完成聚焦。
- 标题和主按钮按阅读顺序出现，总延迟不得让按钮错过首屏可见时间。

### 指针与滚动

- 桌面端人物、产品和软糖仅产生极轻的景深分离。
- 产品最大位移不超过 12px，软糖最大位移不超过 18px。
- 不使用持续漂浮、磁吸人物、鼠标追踪光斑或滚动劫持。
- CTA 只提供焦点、hover 和 active 反馈。

### Reduced Motion

`prefers-reduced-motion: reduce` 下取消位移、视差和延迟编排。人物、产品、文案和按钮从首帧完整可见，信息层级不得依赖动画。

## 8. 组件与数据边界

首屏继续作为 Home Page Pattern 的组成部分，业务内容通过现有 Home Schema 与 Content Adapter 注入。

- Server Component 负责加载和组合已验证内容。
- 需要 Motion 或指针输入的行为必须隔离为 Client Leaf。
- 不在首屏组件中写死产品事实、功效或联系地址。
- 图片地址、替代文本、标题、副文案和 CTA 目标通过现有内容记录提供。
- 不新增全局状态。首屏的轻量动效使用 Motion Value、CSS 或 IntersectionObserver，不监听全局 scroll 事件并触发 React 连续渲染。

## 9. 视觉资产要求

代码实施前需要一张可同时支持桌面和移动裁切的高分辨率主视觉，或一组明确对应的 art-direction 资产。

主视觉必须包含：

- 一位具有真实自然肤感的成年女性局部肖像。
- 一款完整、清晰、可替换标签的女性软糖包装。
- 三至五颗透明红色小熊软糖。
- 冷 Ivory 与 Titanium 柔光环境。
- 左侧可用文字安全区。

不得生成医疗场景、医生白袍、孕妇暗示、身体功效对比或未经批准的包装声明。最终包装文字不清晰时，应使用经批准的概念标签资产进行后期合成，不依赖生成图中的乱码文字。

## 10. 状态与降级

- 图片加载中：保留首屏尺寸和冷 Ivory 背景，文案与 CTA 立即可用，不显示通用圆形 Spinner。
- 图片失败：显示经过设计的冷色背景和明确替代文本，产品识别不得依赖损坏图片图标。
- 联系方式未配置：`START A PROJECT` 仍进入本地 Contact Intake，不伪装成已经提交。
- JavaScript 不可用：标题、文案、产品主视觉、导航与 CTA 路径保持成立。

## 11. 验收标准

首屏实施完成后必须满足：

1. 1440、1280、1024、768、390 和 375px 下标题、按钮、产品包装均在首屏内完整可用。
2. 桌面导航保持单行且高度不超过 80px。
3. Headline 不超过两行，Supporting copy 不超过四行。
4. 产品是第一视觉焦点，人物是情绪背景，软糖是材质线索。
5. 页面不存在大面积粉色、绿色营养频道或蓝色器械频道表达。
6. 页面可见文案不包含功效、认证、销量、价格或伪造参数。
7. 键盘焦点、44px 目标、对比度、替代文本和 Reduced Motion 保持 Phase A 基线。
8. 首屏不产生横向溢出、布局跳动、图片尺寸告警或关键控制台错误。
9. LCP 主视觉只加载当前视口所需资源，桌面与移动资源不重复抢占带宽。
10. 完整 lint、typecheck、unit、build 和 E2E 门禁通过，P0 = 0，P1 = 0。

## 12. 非范围

本规范不授权：

- 重做首页第二屏及后续屏幕。
- 改变主导航、路由或 Contact 字段。
- 创建真实产品功效、配方、剂量、认证或价格。
- 接入 CRM、WhatsApp、邮件、支付、CMS 或 Commerce Provider。
- 安装或启动 Antigravity。
- 开始代码实施。

代码实施必须等待用户完成本书面规范复核，并单独批准实施计划。
