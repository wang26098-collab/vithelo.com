# VITHELO 首页 Hero 高度调整设计

日期：2026-09-03

## 目标

提高首页 Hero 的首屏占比，使其更接近 Seed 参考站点的完整首屏节奏，同时保持 VITHELO 已确认的构图和内容不变。

## 已确认方案

- Hero 高度由现有 `clamp(640px, 88svh, 860px)` 调整为 `min(calc(100svh - 24px), 900px)`。
- 桌面端与移动端统一采用视口驱动逻辑，避免移动端继续被原有 `88svh` 规则压低。
- Hero 背景图继续保持静止；不得缩放、位移、视差或重新生成。
- 标题、正文、按钮、导航和其他首页板块均不调整。

## 验收标准

- 常见桌面视口下 Hero 明显高于当前版本，并接近完整首屏。
- Hero 最大高度不超过 `900px`。
- 移动端内容不被裁切，不出现横向溢出。
- Reduced Motion 与现有导航状态逻辑不受影响。
- 单元测试、lint 与类型检查通过。
