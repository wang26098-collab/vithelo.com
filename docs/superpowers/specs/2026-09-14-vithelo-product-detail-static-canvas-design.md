# VITHELO 产品详情页主图画布与白底布局设计

## 目标

调整 `/products/[slug]` 产品详情页，使其整体参考用户提供的图 2 的信息结构，同时将产品主图的静态画布比例固定为 `945 × 645 px`，并将页面视觉背景调整为白色。

本次修改只针对产品详情页，不重做首页、产品发现页或其他已锁定页面。

## 视觉与布局

- PDP 保持“左侧图库 + 右侧产品信息”的双栏结构。
- 左侧主图使用 `945 / 645` 宽高比的静态画布。
- 主图画布背景为纯白；产品素材使用 `contain`，不得裁切主体。
- 主图下保留四个缩略图入口，继续支持键盘操作和当前图切换。
- 右侧信息栏使用白底、黑色文字和细分隔线，保持 VITHELO 的克制 B2B 视觉。
- 现有 `DEMO_ONLY`、缺失生产输入和 OEM / ODM 询盘语义继续保留。
- 不引入参考图中的 Seed 品牌、绿色主题、功效声明、价格、订阅、购物车或购买文案。

## 响应式行为

- 桌面端采用双栏布局，主图保持 945:645 比例。
- 小屏端改为上下堆叠；主图仍保持比例，不产生横向溢出。
- 右侧信息、参数表和询盘入口在移动端仍保持可读和可操作。

## 交互与可访问性

- 保留现有主图前后切换、缩略图切换、焦点样式和 `aria-pressed` 状态。
- 保留面包屑和产品详情语义结构。
- 不新增服务端提交、购物、支付、CRM 或未配置数据连接。
- 视觉调整不得让关键 `DEMO_ONLY` 状态只依赖动画或颜色表达。

## 验收标准

1. 产品主图容器的计算比例为 `945 / 645`，素材不被裁切。
2. 产品详情页背景、主图画布和右侧信息区域均为白色视觉基底。
3. 桌面端呈现左图右信息的双栏布局，右侧参数和询盘 CTA 清晰可见。
4. 现有图库切换、缩略图切换、键盘焦点和移动端堆叠行为不回归。
5. VITHELO 公共身份、`DEMO_ONLY` 证据边界和现有内容数据不被改变。
6. 相关定向测试、类型检查和构建通过；不以修改 `独立站内容/` 参考脚本来满足全局 lint。

## 不在本次范围内

- 不生成新的产品静态拼贴图或替换现有产品素材。
- 不复制参考图的品牌资产、绿色频道、功效、价格或购买流程。
- 不调整首页八屏结构、Hero artwork、导航或已接受的其他页面。
