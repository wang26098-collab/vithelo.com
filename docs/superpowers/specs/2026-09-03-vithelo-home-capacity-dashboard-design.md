# VITHELO 首页第三屏制造能力仪表盘设计

日期：2026-09-03

## 目标

在首页新增独立的制造能力仪表盘，作为第三屏承接第二屏的制造证明，并在进入软糖能力与产品叙事前提供可快速扫描的规模信息。

## 页面位置

首页调整为八屏：

1. Hero
2. 制造证明
3. 制造能力仪表盘（新增）
4. 软糖能力
5. 产品方向
6. 产品剂型
7. OEM / ODM 项目路径
8. 询盘收口

原第三屏及之后内容整体顺延，内部内容和相对顺序不变。

## 视觉结构

- 深色冷调背景，延续 VITHELO 的 Graphite / Titanium 体系，不复制参考图的绿色。
- 标题使用 `Built to scale across formats.`。
- 左侧为四格白色数据账本：
  - `8` — Dosage formats
  - `50B` — Softgels / year
  - `5,000+ t` — Gummies / year
  - `36B` — Tablets / year
- 右侧为白色流程面板，用四个节点表达 `Formulation → Sampling → Scale-up → Packaging`。
- 不使用 `audited`、虚构年度增长曲线、未经核验的认证或占位数字。
- 数据区域保留“用户提供资料、待生产核验和公开使用批准”的来源边界。

## 动效

- 屏幕进入视口时，标题、数据格和流程节点依次揭示。
- 数据使用一次性递增展示；最终数值始终存在于 DOM，Reduced Motion 直接显示最终状态。
- 流程连接线使用轻量绘制动效，不使用滚动劫持、循环动画或大幅位移。
- 鼠标悬停数据格时只做轻微聚焦和边界响应，不改变信息顺序。

## 响应式与可访问性

- 桌面端保持参考图的左宽右窄双面板比例。
- 移动端依次显示标题、两列数据格、单列流程节点。
- 内容顺序与视觉顺序一致；数据不依赖颜色或动画理解。
- 所有重要文字满足对比度要求，Reduced Motion 显示完整信息。

## 验收标准

- 首页存在八个顶层 section，新屏严格位于第二屏与软糖屏之间。
- 四项数据与来源边界完整显示。
- 页面中不存在 `audited` 或虚构的 2020–2025 增长信息。
- 六个验收视口无裁切、重叠或横向溢出。
- lint、类型检查、单元测试、E2E 与构建通过。
