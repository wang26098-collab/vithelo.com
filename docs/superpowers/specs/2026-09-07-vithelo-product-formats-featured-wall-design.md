# VITHELO 首页第六屏 Featured Format Wall 设计规范

日期：2026-09-07  
状态：视觉方向已确认

## 目标

将首页第六屏 `06 · Product Formats` 从紧凑的八格卡片改为图像主导的剂型作品墙。参考 Lusion `Featured Work` 的视觉机制：大标题进入、双列大幅媒体、连续纵向浏览、图像随滚动产生克制的缩放和位移、名称紧贴媒体下方。

本次只修改第六屏及其直接关联的内容、媒体、动效和测试。Hero、第二至第五屏、第七屏和第八屏保持不变。

## 已确认方向

名称：`Featured Format Wall`

选择方案 A：八种剂型全部出现在同一内容区，桌面为四行两列的作品墙，手机为八项单列。页面使用浏览器原生纵向滚动，不固定在一个屏幕内切换，不使用横向轮播、页码、左右箭头或滚动劫持。

## 内容结构

章节标识：`06 · PRODUCT FORMATS`

主标题：`One system. Eight expressions.`

说明：`Explore eight product formats through one coordinated manufacturing system.`

八种剂型按现有内容顺序完整保留：

1. Gummies
2. Hard Capsules
3. Softgels
4. Tablets
5. Powders
6. Liquids
7. Functional Gum
8. Oral Films

每项包含：两位编号、大幅剂型媒体、剂型名称、通往对应 `/products/[slug]` 页面的一致入口。首页不重复八次 MOQ 文案；统一的 MOQ 边界说明放在作品墙标题区或底部说明区。

## 桌面构图

- 第六屏以冷象牙背景承接第五屏，保持 VITHELO 的石墨、钛灰与克制暖珊瑚体系。
- 开场使用大号 `Product Formats` 或正式主标题，标题占据约半个至三分之二视口高度，形成进入作品墙的章节幕。
- 八项媒体采用两列、四行结构，列间距小于行间距。
- 右列整体向下错位约一个媒体标题区的高度，形成 Lusion `Featured Work` 式不完全对齐节奏。
- 每项媒体以横向画幅为主，画面占卡片绝大部分；编号、名称和箭头位于媒体下方的一条细分隔线上。
- 不使用圆角卡片墙、统一白底容器、悬浮阴影盒或彩色渠道主题。
- Gummies 与 Oral Films 的视觉权重相同；任何单项不得跨两行或被孤立。

## 媒体方向

正式实现需要八张剂型专属视觉，不能继续用 CSS 渐变圆形代替产品图，也不能让八项复用同一张产品图。

- Gummies：软糖质感或 VITHELO 软糖包装场景。
- Hard Capsules：硬胶囊微距或包装与胶囊组合。
- Softgels：透明软胶囊的光泽与液体感。
- Tablets：片剂几何、粉质边缘与包装组合。
- Powders：粉末扩散、量勺或袋装体系。
- Liquids：滴剂、液体瓶或液体流动质感。
- Functional Gum：功能口香糖片或板装体系。
- Oral Films：薄膜片、独立袋装与半透明材质。

媒体只展示可确认的剂型和包装形式，不生成或烘焙功效、剂量、认证、价格、数字 MOQ、法规或第三方品牌文字。公开品牌只允许 `VITHELO`。

## 滚动与交互

动效意图为 `RELATE`，用于建立“一个制造系统与八种剂型表达”的关系。

进入标题区时：

1. 章节标识保持稳定可读。
2. 大标题随进入视口由下向上轻量揭示，字形不进行持续扭曲。
3. 说明文字稍后进入，完成从章节幕到作品墙的过渡。

浏览作品墙时：

1. 每个媒体窗口在进入视口时由 `translateY(40–64px)` 和轻微透明度变化进入最终位置。
2. 媒体内部图片在整个可见过程进行约 `1.08 → 1.00` 的缩放，并产生不超过图片高度 6% 的纵向位移。
3. 左右两列因垂直错位形成交替节奏，但滚动距离仍由内容自然决定。
4. 鼠标悬停或键盘聚焦时，当前图片轻微放大，其他项目不整体变暗；名称箭头移动不超过 4px。
5. 点击名称或媒体进入对应剂型详情页。

禁止持续漂浮、鼠标追踪 3D、WebGL 粒子、自动轮播、吸附滚动和强制控制滚轮。

## 响应式

- 1280px 以上：两列四行，右列错位，媒体保持宽幅比例。
- 761–1279px：仍保持两列，但缩小列间距和标题字号；媒体名称允许自然换行。
- 760px 以下：转为单列八项，取消列错位；每项媒体先于名称，保持完整阅读顺序。
- 所有断点不得出现横向溢出，触控目标不小于 44px。
- 第六屏允许超过一个视口，因为作品墙本身承担连续浏览任务；不强行压缩八项到一屏。

## Reduced Motion 与无障碍

- Reduced Motion 下取消所有视差、缩放、位移和错开延迟，八种剂型以最终状态直接显示。
- DOM 顺序与视觉阅读顺序一致：桌面按行从左到右，手机从上到下。
- 每张图片使用描述剂型而非营销功效的英文替代文本。
- 媒体与名称共用清晰的可访问链接名称；焦点状态必须可见。
- 装饰性编号和分隔线不重复进入读屏语义。

## 验收标准

- 第一眼明显接近 Lusion `Featured Work` 的大标题与双列作品墙机制，但视觉语言属于 VITHELO。
- 八种剂型全部出现且视觉权重平衡，Oral Films 不被孤立。
- 页面依靠原生纵向滚动连续浏览，不出现轮播或滚动劫持。
- 每种剂型有独立、真实可用的媒体视觉，不以 CSS 几何图形作为正式交付。
- 滚动缩放和位移克制，文字稳定可读，不发生图片压字或卡片重叠。
- 手机为单列大图且无横向溢出。
- Reduced Motion 下内容完整，八个详情链接可通过键盘访问。
- 不出现第三方品牌、价格、数字 MOQ、未经核实的功效、认证或法规声明。
- 其他七屏不因本次实现被重新设计。
