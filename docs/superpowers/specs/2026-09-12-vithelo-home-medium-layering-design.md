# VITHELO 首页前三屏中度层叠设计

## 决策结论

用户已确认采用“中度层叠”，首轮只验证首页前三屏：Hero → 制造证明 → 三款主打产品。

本轮借鉴 Nordicus 首页的页面板覆盖关系与留白秩序，不复制其建筑作品集风格、字体、文案、素材或页面结构。VITHELO 继续保持冷象牙、石墨、钛金属与克制光学感的既有视觉世界。

## 真实问题

当前目标不是增加更多滚动动画，而是让前三屏从彼此独立的内容区，变成一段有前后关系的连续品牌叙事：Hero 建立身份，制造证明承接信任，主打产品把能力转化为可见成果。

## SLC 范围

### Must

- 保持 Hero 现有素材、尺寸、定位和静止状态。
- 保持前三屏顺序、现有屏高、屏内上下间距和左右间距。
- 使用浏览器原生纵向滚动，不使用滚动劫持。
- 通过整屏表面的遮盖关系建立层叠，不把屏内内容拆成新的卡片。
- 桌面、平板和手机均保持标题、制造事实、产品名称与操作入口稳定可读。
- Reduced Motion 下保留静态层级关系，不依赖运动才能理解内容。

### Should

- 第二屏和第三屏在进入前先露出一小段上沿，形成下一章节预告。
- 使用统一但响应式收敛的上沿圆角。
- 依靠象牙色、石墨色和细微边界变化区分层级，不依赖厚重阴影。
- 层叠只服务于叙事承接，不抢夺制造证明和产品内容的注意力。

### Could

- 在面板上沿增加极轻的钛金属高光线，帮助浅色表面从背景中分离。
- 在不改变内容位置的前提下，让面板进入时产生极短距离的自然显现。

### Won't

- 不改 Hero，不增加 Hero 缩放、位移、视差或文案入场。
- 不让任何一屏长时间吸顶，也不形成连续堆叠的滚动演示。
- 不把八屏全部改造成大圆角卡片。
- 不改第四至第八屏，不影响第五屏纵向故事、第六屏八剂型或第八屏询盘揭示。
- 不引入建筑作品集式字体、暖棕滤镜、项目编号或参考站品牌元素。
- 本设计阶段不书写实现代码，不推送或部署。

## 视觉结构

### 第一层：Hero 基底

- Hero 是固定的视觉基底，但不采用 `sticky` 或视差行为。
- 现有画面、文案、按钮和导航保持当前状态。
- Hero 下沿不额外加圆角；覆盖关系由第二屏的上沿完成。

### 第二层：制造证明板

- 制造证明成为第一张冷象牙色“内容板”，从 Hero 下方自然进入并覆盖 Hero 下沿。
- 只处理整屏外轮廓：桌面上沿圆角建议 40px，平板 32px，手机 20px。
- 视觉覆盖距离建议：桌面 40px，平板 32px，手机 20px。
- 屏内文字、数据、制造场景与能力条目的现有网格和间距不变。
- 表面保持平整，不使用漂浮卡片阴影；如需分层，仅使用低对比度边界或极轻高光。

### 第三层：主打产品板

- 三款主打产品作为第二张内容板，在制造证明板之后自然覆盖进入。
- 圆角与制造证明板同一套响应式尺度，避免每屏产生不同视觉语法。
- 覆盖距离略小于第二屏：桌面 32px，平板 24px，手机 16px，使节奏由强转稳。
- 三款产品仍属于同一屏，不把每个产品各自做成滚动叠卡。
- 第三屏完成后恢复现有第四屏衔接，不在首轮扩展新的层叠规则。

## 滚动体验

- 层叠的主体是页面板之间的几何覆盖，而不是持续计算的滚动动画。
- 用户向下滚动时，下一屏上沿先出现，随后其完整内容自然进入视口。
- 上一屏不缩小、不模糊、不降低透明度，也不滞留在屏幕中央。
- 不增加进度条、滚动提示、页码、左右箭头或强制停顿。
- 若使用进入过渡，只允许一次、短距离、低振幅的表面显现；内容可读性不得等待过渡完成。

## 干净感规则

- 一屏只保留一个主要视觉焦点，层叠边缘不承担额外信息。
- 不新增装饰性胶囊标签、圆角小卡、渐变按钮或悬浮玻璃面板。
- 屏间层次主要来自大面积材质反差、留白和上下边界，不来自阴影堆积。
- 圆角只出现在整屏内容板的上沿；屏内组件继续遵守现有设计系统。
- 参考站约 60px 的大圆角不直接照搬，避免 VITHELO 变得柔软、生活方式化或作品集化。

## 响应式行为

### 桌面

- 层叠感最完整，第二屏 40px 覆盖、第三屏 32px 覆盖。
- 保持当前最大内容宽度与左右框架基线。

### 平板

- 覆盖距离与圆角同步收敛，避免两列产品布局被外轮廓压迫。
- 不改变现有平板产品排列。

### 手机

- 只保留明确但轻量的上沿覆盖：第二屏 20px、第三屏 16px。
- 圆角降至 20px，不增加左右内缩，避免内容板像独立小卡片。
- 菜单、标题换行、44px 操作目标和正常页面滚动优先于层叠表现。

## Reduced Motion 与可访问性

- Reduced Motion 下不执行跟随滚动的位移、缩放、透明度或模糊变化。
- 静态圆角与覆盖关系可以保留，因为它们不影响信息出现时机。
- 键盘焦点进入第二屏或第三屏时，目标内容必须直接可见，不等待装饰过渡。
- 所有事实、产品名称和 CTA 在无 JavaScript 状态下保持完整。

## 验收标准

- Hero 画面、定位、尺寸、静止状态和现有文案布局与当前锁定基线一致。
- 前三屏顺序、屏高、上下间距和左右间距不变。
- 从 Hero 进入制造证明时能明确感知页面板覆盖，但不存在吸顶、缩放或滚动阻尼。
- 从制造证明进入主打产品时仍有层次，同时视觉强度低于第一次转场。
- 三款产品仍在同一完整屏内，产品内容不被拆成滚动卡片。
- 第四屏及其后的现有体验没有发生变化。
- 六个验收视口无横向溢出、内容裁切、焦点遮挡、圆角露底或层级穿帮。
- Reduced Motion、无 JavaScript 和键盘导航均可直接获得完整信息。
- 视觉验收时，页面应被描述为“连续、克制、干净”，而不是“卡片很多、动画明显或像建筑作品集”。

## 后续闸门

本文件只锁定设计方向。下一步若进入实施，应先编写独立实施计划，并仅修改前三屏衔接所需的最小范围。完成定向验证和六视口视觉检查后，再由用户决定是否将同一语言扩展到第四至第七屏。
