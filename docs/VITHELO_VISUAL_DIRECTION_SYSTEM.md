# VITHELO Visual Direction System

> 版本：2026-09-06  
> 状态：视觉规划基线，待用户审核  
> 范围：只定义品牌官网的视觉表达规则，不修改页面、路由、导航、SEO、证据治理或询盘流程。

## 0. 使用方式

本文件是后续首页与内页设计的视觉总纲。所有页面先按照本文件形成：

```text
Business Message
        ↓
Visual Story
        ↓
Evidence Support
```

不得反过来从数据字段、审核状态或组件库存推导页面视觉。

Evidence Governance 继续保留，但它是内容可信度的底层约束，不是客户看到的主视觉。`Evidence required`、`Not configured`、`Pending verification` 等状态只允许存在于内部数据、管理工具、开发验收或必要的低干扰披露语境中；不得成为公开页面的标题、英雄数字、主卡片标题、主要导航词或视觉焦点。

## 1. Brand visual positioning

### 1.1 品牌定位

VITHELO 是：

**Global Nutrition OEM/ODM Manufacturing Partner**

网站面对的是正在评估合作伙伴的专业买家：营养品品牌、私人标签公司、产品经理和采购团队。他们需要快速判断三件事：

1. 这家伙伴是否理解我的产品与商业目标；
2. 这家伙伴是否具备把想法推进到稳定交付的能力；
3. 我是否可以自然、明确地开始一次项目沟通。

因此网站不是“信息总表”，而是一段从信任建立到项目启动的品牌体验：

```text
Recognize the opportunity
        →
Feel the manufacturing confidence
        →
Understand the route to market
        →
Start a qualified conversation
```

### 1.2 VITHELO Visual DNA

| 关键词 | 视觉含义 |
| --- | --- |
| Premium | 大尺度构图、克制细节、材料与光线有品质，不靠装饰性金属或过度渐变表达昂贵。 |
| Scientific | 结构清晰、信息准确、图像有研发与材料观察感；科学感来自秩序与细节，不来自医院蓝、实验室表格或医疗符号。 |
| Trustworthy | 事实可追溯，语气稳定，视觉不夸张；以真实场景、清晰层级和适度说明建立可靠感。 |
| Modern Manufacturing | 关注过程、材料、设备、包装和协作场景；呈现制造能力的质感，而不是工厂目录。 |
| Global | 留白、节奏、语言和图像具有国际品牌气质；避免低价外贸模板和本地供应商海报感。 |
| Clean Nutrition | 轻盈、纯净、可感知的材料表达；避免把 Nutrition 变成绿色频道，也避免空泛的健康生活方式图库。 |

### 1.3 必须避免的品牌误读

视觉上不能让访客首先联想到：

- Audit Dashboard：数字、状态、标签和边框主导页面；
- Internal Review Tool：内部任务、审查、配置、状态流转成为页面语言；
- Compliance Report：证据编号、灰色占位、审核结果成为主叙事；
- Generic Factory Website：厂房大楼、握手、流水线全景与口号的通用组合；
- Medical Hospital Style：临床蓝、白色无菌空间、医疗十字或诊疗界面；
- Amazon Product Listing：密集卖点、产品缩略图矩阵、促销角标和规格堆叠。

## 2. Layout system

### 2.1 总体构图原则

采用 **Editorial Manufacturing Narrative**：编辑式叙事与制造现场的真实质感结合。

- 先建立一个主张，再让图像或空间承载它；
- 用不对称的比例制造品牌节奏，而不是用均等卡片填满屏幕；
- 每个 Section 只设一个主要视觉焦点和一个主要商业任务；
- 数据和证据作为叙事中的“支撑层”，不抢夺品牌主张；
- 允许空白成为内容的一部分，页面不追求每个区域都有组件；
- 让图片、标题、短文和 CTA 形成连续阅读路径。

### 2.2 页面节奏

首页与内页都遵循四种节奏交替：

1. **Arrival**：宽阔、明确、快速让人理解 VITHELO 的角色；
2. **Immersion**：让访客进入材料、产品、研发或制造场景；
3. **Orientation**：用少量结构化信息帮助买家做判断；
4. **Invitation**：把理解转成下一步项目沟通。

避免连续多个“信息密集 Section”，也避免连续多个纯氛围大图。每个密集信息区之后应有呼吸空间或图像缓冲。

### 2.3 比例与网格

- 保持宽幅容器和流动边距，桌面端优先使用 55/45、60/40、65/35 等有主次的比例；
- 文字列应保持可读宽度，长段落不横跨整屏；
- 重要视觉可跨越多列，辅助信息落在窄列或基线区域；
- 允许图片出血、错位和跨行，但必须服务于阅读顺序；
- 规则线只用于划分节奏、建立对齐和强调层级，不用于把页面切割成表格；
- 移动端不是桌面端的缩小版：按照“主张 → 图像 → 解释 → 行动”重新排序；
- 不使用横向滚动承载核心信息，不让买家依赖拖动或轮播才能理解内容。

### 2.4 Section 空间规则

- Hero 需要足够的首屏呼吸空间，让定位与主图形成主导关系；
- 普通叙事 Section 使用宽松的上下间距，优先形成一屏一个节奏单元；
- 证据密集区也必须保留视觉留白，不以大量细线和小字号压缩信息；
- 同一 Section 内的内容层级最多三层：主张、解释、支撑；
- 留白不能被“填充型卡片”侵占；空白区域应帮助突出材料、产品或主标题。

### 2.5 视觉锚点

每个 Section 开始前必须回答：访客第一眼看哪里？第二眼理解什么？第三步如何行动？

优先级通常为：

```text
Brand / Business message
        →
Human or material image
        →
Capability explanation
        →
Evidence / CTA support
```

## 3. Typography system

### 3.1 字体角色

延续现有冷调、精确的 neo-grotesk 基础字体，重点重新建立层级，而不是引入装饰性字体。

- **Hero Display**：承担品牌定位和核心承诺，字号大、行高紧、字重有力量；每屏只允许一个主要 Display 信息。
- **Section Statement**：表达商业主题，例如能力、产品方向、协作路径；要像品牌编辑标题，而不是字段名称。
- **Body Copy**：解释价值、场景与下一步，保持短段落、自然行宽和足够行距。
- **Utility Label**：用于导航、分类、时间、格式名称或轻量上下文；不承担主语义。
- **Evidence Note**：用于必要的来源或边界说明，视觉弱化但保持可读；不得伪装成主标题或营销卖点。

### 3.2 层级规则

- H1 只表达定位或本屏最高级商业命题；
- H2 直接回答“这一段为什么对买家重要”；
- H3 用于产品格式、服务动作或内容入口，不作为数据字段标题；
- 正文优先使用 1–3 句完成一个观点；
- 标签和说明不能与标题使用同等视觉重量；
- 数字可以成为视觉焦点，但必须嵌入一个商业语境，例如 capacity、formats、markets 或 project stages，而不是孤立的大数字墙；
- 避免全大写长句、过度字距、连续粗体和满屏小标签。

### 3.3 文案与视觉关系

公开文案使用客户语言：capability、formats、product direction、project path、manufacturing environment、quality approach、global partnership。

内部治理词不作为客户主视觉：evidence required、not configured、pending verification、source record、audit status 等。如必须保留边界，应放在低干扰的上下文说明中，且不削弱主要商业信息的阅读体验。

## 4. Color direction

### 4.1 主色世界

保持 VITHELO 的冷调中性基底：

- **Cold Ivory**：主背景与大面积呼吸空间，传达纯净、克制和营养品的轻盈感；
- **Graphite**：主要文字、核心对比和重要行动，传达稳定与专业；
- **Titanium**：边界、细节、图片辅助层和结构线，使用要轻；
- **Optical Light**：焦点、交互反馈和局部光感，保持克制；
- **Material Accent**：只在真实产品材料或场景需要时出现，不能形成 Nutrition 绿色频道或页面状态色体系。

### 4.2 色彩使用比例

建议大部分页面由 Ivory、Graphite 与低对比 Titanium 构成。色彩的作用是建立氛围与层级，不是编码数据状态。

- 不用绿色表示营养品能力；
- 不用蓝色制造廉价“科技/医疗”感；
- 不用红、橙等高饱和色制造促销感；
- 不用深色背景连续包裹所有 Section；
- 不用渐变和发光效果替代真实图片与空间层次。

### 4.3 对比与可读性

颜色不能成为唯一状态表达。任何重要事实、CTA、错误或边界都必须有清晰文字和语义；视觉弱化不能变成不可读或隐藏信息。

## 5. Image direction

### 5.1 图像角色

图片是品牌叙事的主语之一，不是卡片背景或填充物。优先使用：

1. **Product Photography**：剂型、包装、材料和成品的精致细节；
2. **Manufacturing Scene**：真实的生产、灌装、压片、软糖或包装环境；
3. **R&D Scene**：配方、材料、观察、样品与研发协作；
4. **Packaging Scene**：从产品概念走向货架与市场的视觉线索；
5. **Partnership Scene**：产品经理、采购或研发团队的协作瞬间；
6. **Material Field**：用于转场或抽象表达的营养品材料、粉体、胶体、薄膜与透明质感。

### 5.2 摄影气质

- 真实、近距离、有材料触感；
- 光线自然或经过精确控制，避免过度 HDR 和假工厂渲染；
- 构图有留白，给标题和行动留出自然空间；
- 重点呈现手、材料、设备局部、包装细节和过程关系，而不是只拍厂房外观；
- 画面应有编辑摄影的选择性，不把所有可见信息同时塞进一张图；
- 图像裁切服从页面节奏，同时尊重真实场景，不因装饰而制造误导。

### 5.3 证据边界下的图像处理

若某张图片不能支撑一个可公开的事实，不得通过标题、叠字、徽章或强烈视觉处理把它包装成证据。可以使用品牌视觉表达来建立材料、过程和专业气质，但不得让代表性图片暗示未经核验的认证、参数、产能、客户或法规结论。

缺少公开证据时，优先：

- 使用不承载具体事实的材料与过程画面；
- 使用已允许的真实场景或产品图；
- 删除该视觉模块，保持页面完整；
- 通过“能力方向”和“项目路径”表达，而不是展示灰色缺失状态。

## 6. Component style

### 6.1 组件总体原则

组件必须服务于品牌叙事。优先使用少量、可重复但不模板化的原语：

- Editorial split：一侧主张，一侧图像或材料；
- Image-led statement：大图先建立感受，文字负责解释；
- Capability index：少量能力入口或格式导航，强调阅读与选择；
- Process runway：把 OEM/ODM 过程表现为连续路径，而不是状态表；
- Proof detail：在主叙事之后提供可追溯数字、来源或说明；
- Inquiry close：用明确、低摩擦的行动收口。

### 6.2 Card strategy

卡片不是默认容器。只有在以下目的成立时才使用：

- 比较不同产品格式或项目选项；
- 导航到独立内容或下一步动作；
- 让复杂信息形成可扫描的分组；
- 保护一个独立的交互区域。

卡片需要有明确的阅读动作，不得只是把字段包进边框。默认使用开放布局、图片、规则线、留白和层级完成组织；圆角、阴影和重复边框都应克制。

### 6.3 Data and evidence presentation

数据要以“商业能力证明”的方式出现：

- 先说数据对买家意味着什么，再显示数字；
- 数字配合明确的能力语境，不做孤立 KPI 墙；
- 来源和边界采用低干扰说明，不以大字、警示色或状态徽章占据视觉中心；
- 不把未核验内容写成已完成的承诺；
- 不用表格作为首页主要叙事结构；
- 必须保留的治理状态进入内容层和适当的辅助 UI，不进入品牌英雄层。

### 6.4 CTA 与交互

- CTA 是项目邀请，不是 SaaS 操作按钮；
- 主要行动使用清晰动词：Explore formats、Discuss your project、Talk to manufacturing、Start an inquiry；
- 按钮有足够尺寸、清晰焦点和触控空间；
- 主要 CTA 每个视觉单元最多一个，次要行动采用文本链接或低权重按钮；
- Email、WhatsApp 和现有 Contact 流程保持不变，只重新表达其视觉语气；
- 不使用“查看状态”“提交审核”“配置证据”等内部工具式动作词作为公开 CTA。

## 7. Motion style

### 7.1 动效目标

动效只用来强化品牌节奏和理解，意图优先级为：

- **ORIENT**：帮助访客理解页面入口与阅读方向；
- **RELATE**：建立图像、材料与文案之间的关系；
- **EXPLAIN**：渐进呈现复杂能力或项目路径；
- **FOCUS**：把注意力收束到一个关键画面或商业主张；
- **CONFIRM**：反馈 CTA、菜单和必要的交互结果。

### 7.2 动效气质

- 轻、慢、准确，像编辑排版和材料观察，而不是 SaaS 仪表盘刷新；
- 优先使用 opacity、translate、clip 或规则线展开等低干扰变化；
- 图像尽量静止，尤其是 Hero 和承载事实的图片；
- 不使用数字滚动、进度条、仪表盘计数、无限循环或视差来制造能力感；
- 不让关键事实只在动效完成后才可见；
- Reduced Motion 下完整内容直接可见，布局和信息层级不发生损失。

### 7.3 节奏

进入视口后的动效应有清晰顺序：主张 → 图像关系 → 辅助解释 → 行动或支撑信息。连续动画元素要少，避免让整页像监控界面持续刷新。

## 8. Forbidden visual patterns

以下模式视为视觉方向偏离，后续设计和实现必须主动排除：

### 8.1 审核系统感

- `Evidence required`、`Not configured`、`Pending verification` 作为公开主标题或视觉焦点；
- 大型 `NOT_CONFIGURED`、状态徽章、审核标签、证据编号墙；
- 四宫格或多宫格状态卡堆叠；
- 表格、字段列表、灰色占位块承担首页主要叙事；
- 用边框数量、状态颜色和小字密度制造“系统完整性”。

### 8.2 廉价供应商感

- 厂房外观、集装箱、握手、奖杯、证书墙的通用图库组合；
- “best quality / professional factory / one-stop solution” 等空泛大口号；
- 过度促销的数字、角标、爆炸贴和大面积高饱和按钮；
- Logo、证书、国家旗帜和客户数量的密集陈列；
- 以产品白底缩略图和规格字段组成的供应商目录首页。

### 8.3 SaaS / Dashboard 感

- KPI 仪表盘、进度环、雷达图、监控条、实时状态动效；
- 每个内容都封装成统一高度、统一圆角、统一阴影的卡片；
- 侧边栏、标签页、筛选器或数据表成为品牌主导航之外的视觉骨架；
- 细小 UI 标签多于真实图像和品牌主张；
- 通过 hover、滚动或轮播才能获得核心信息。

### 8.4 医疗或伪科学感

- 医院蓝、荧光青、十字、诊疗界面、人体器官和临床图库；
- 未核验的 clinical、certified、approved、tested 等词被视觉强化；
- 用分子、DNA、实验室玻璃器皿等陈词滥调代替真实材料与过程；
- 以复杂图表、技术参数或伪精密线稿暗示未公开的技术能力。

### 8.5 通用品牌模板感

- 每个 Section 都使用相同的标题 + 三张卡片 + CTA 模板；
- 过度依赖渐变、玻璃拟态、发光边框和装饰性网格；
- 为了“高级”加入无意义的黑色大块、金属纹理或奢华衬线字体；
- 所有图片都被裁成相同比例，失去场景与内容差异；
- 视觉风格只剩“干净”，却没有产品、制造和合作的具体性。

## 9. Design review checklist

每个新 Section 在进入代码前必须通过以下检查：

- 它是否先表达一个清晰的商业信息，而不是一个数据字段？
- 第一眼是否是品牌主张、产品或真实场景，而不是状态标签？
- 图像是否承担了真实的视觉叙事，而不是填充空白？
- Evidence 是否支持主张而不是取代主张？
- 页面是否存在足够留白与主次关系？
- 组件是否有比较、导航、理解或行动的明确任务？
- 删除所有边框、标签或卡片后，核心故事是否仍然成立？
- 桌面与移动端是否都保留“主张 → 理解 → 行动”的路径？
- Reduced Motion 是否仍能完整传达信息？
- 是否意外引入了未经核验的能力、认证、客户、产能、参数或合规暗示？

## 10. 后续工作边界

本文件完成后，工作暂停在视觉语言确认阶段。下一步必须先由用户审核本系统，确认后才可进入 Homepage Structure；在首页结构确认前，不进入 Homepage redesign，也不进入 Products、OEM/ODM、Manufacturing 或 Quality 页面设计与代码实现。
